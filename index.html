Cascading Style Sheet

Core Foundation

1. What It Does (Plain English)

"Cascading" means styles flow downwards like water down steps. When multiple CSS rules target the exact same HTML element, the browser uses rules of priority (source order and specificity) to decide the winner. If two rules have identical weight, the last written rule wins.

2. How It Works in CSS

  • color: blue; is read first by the browser engine.
  • color: #e11d48; is read a line later, so it replaces the previous value.
  • Inline styles (on the HTML tag itself) override external stylesheets because they have higher specificity.
💡 Pro Tip: If your CSS isn't applying, check if another rule lower down in your file is silently overriding it!
Live Visual Preview
Cascaded Result: Rose Red overrides Blue!
CSS Rule Order Demonstration
/* Rule 1: declared first */
.cascade-box {
  background-color: #2563eb; /* Blue (overridden) */
}

/* Rule 2: declared lower in the stylesheet (WINS!) */
.cascade-box {
  background-color: #e11d48; /* Rose Red overrides blue */
  color: #ffffff;
}

Basic Syntax

Syntax

1. What It Does (Plain English)

Every CSS rule follows a 3-part blueprint: Selector (Who to style), Property (What to change), and Value (How to change it). Together, properties and values inside curly braces form a declaration block.

2. How It Works in CSS

  • Selector: Matches elements on the page (e.g. .syntax-card).
  • Declaration Block: Enclosed by { and }.
  • Declaration: property: value; ended with a mandatory semicolon.
⚠️ Watch Out: Forgetting the semicolon ; at the end of a line is the #1 reason beginners break subsequent styles!

  background-color: #fef08a;    /* background color declaration */
  border: 2px dashed #ca8a04;   /* border shorthand declaration */
  padding: 14px;                /* internal spacing declaration */
}

Including Style (3 Methods)

Setup

1. What It Does (Plain English)

There are 3 ways to connect styling to an HTML document: Inline (directly inside an HTML tag attribute), Internal (inside <style> tags in the head), and External (linked via an external .css file).

2. How It Works in CSS

  • External (Recommended): One style.css file keeps HTML squeaky clean and can style 100+ pages at once.
  • Internal: Good for single-page tests or email templates.
  • Inline: Takes highest precedence but creates messy, duplicate HTML.
💡 Best Practice: Always use External CSS for real projects. It enables browser caching, making your website load noticeably faster!
Live Visual Preview
Inline Method: style="color: #9f1239;"
External Method: styled cleanly in style.css
All 3 Inclusion Techniques
<!-- 1. External CSS (Industry Standard): Place inside <head> -->
<link rel="stylesheet" href="style.css">

<!-- 2. Internal CSS: Inside <head> of single document -->
<style>
  h2 { color: #2563eb; }
</style>

<!-- 3. Inline CSS: Directly on element tag -->
<p style="color: #9f1239; font-weight: 600;">Styled on tag</p>

Selectors (Universal, Element, Class, ID, Grouping, Descendant)

Selectors

1. What It Does (Plain English)

Selectors are targeting expressions that tell CSS which HTML tags to grab and style. You can target all elements, single tag types, reusable classes, unique IDs, multiple tags grouped together, or nested children.

2. How It Works in CSS

  • * : Universal (applies to every tag).
  • div : Element tag selector.
  • .pill : Class selector (starts with dot; reusable).
  • #avatar : ID selector (starts with hash; unique per page).
  • h1, h2, h3 : Grouping (comma separates targets).
  • .parent span : Descendant (target span inside .parent).

Units in CSS (Absolute vs Relative)

Sizing

1. What It Does (Plain English)

Units tell the browser how large to render elements. Absolute units (like px) are locked and never change. Relative units (%, em, rem, vw, vh) resize adaptively depending on parent sizes, root font-size, or screen dimensions.

2. How It Works in CSS

  • 150px : Fixed absolute screen pixels.
  • 80% : 80% of whatever container width the parent provides.
  • 1.5rem : 1.5 × the root <html> font size (usually 16px × 1.5 = 24px).
  • 30vw : 30% of the active browser window width.
💡 Modern Rule: Use rem for font sizes and spacing so users who scale text in their OS/browser settings get accessible, comfortable reading!

Box Model & box-sizing: border-box

Layout Core

1. What It Does (Plain English)

Every single HTML element is an invisible rectangular box built with 4 layers: Content (the inner payload), Padding (space around content), Border (the frame), and Margin (empty buffer pushing other elements away).

2. How It Works in CSS

  • By default in old CSS, adding 20px padding made a 100px box expand to 140px!
  • box-sizing: border-box; solves this forever: padding and border are factored inside the width you set.
⭐ Golden Rule: Always put * { box-sizing: border-box; } at line 1 of every stylesheet you ever write!
Live Visual Preview (4 Nested Layers)

PADDING (Inner Room)

The Box Model in Action
* { box-sizing: border-box; } /* Padding won't blow up box width! */

.box {
  width: 200px;              /* Exact final width */
  padding: 16px;             /* Internal cushion */
  border: 4px solid #10b981; /* Frame */
  margin: 16px;              /* Outer buffer space */
}

Display Property (block, inline, inline-block, none)

Layout

1. What It Does (Plain English)

Controls how elements flow and share space on screen: taking up the entire row (block), sitting side-by-side inside text lines (inline), or sitting side-by-side while respecting custom width/height (inline-block).

2. How It Works in CSS

  • inline-block: Best of both worlds: flows inline, but honors your width/height.

Visibility (visible vs hidden vs display: none)

Layout

1. What It Does (Plain English)

When hiding an element, you must choose whether to collapse its physical footprint. display: none deletes it from page flow (neighbor elements shift into its spot). visibility: hidden makes it invisible like a ghost, but keeps its blank slot reserved.

2. How It Works in CSS

  • display: none; → Box vanishes completely, layout collapses.
  • visibility: hidden; → Box is transparent, but blank gap remains.

Alpha Channel (opacity vs rgba())

Colors

1. What It Does (Plain English)

The Alpha Channel controls transparency. The common beginner bug is using opacity when they only wanted a see-through background. opacity fades the entire container plus all text inside. rgba() only fades the background color, keeping text 100% crisp!

2. How It Works in CSS

  • opacity: 0.45; applies to whole element tree (0 = clear, 1 = solid).
  • rgba(225, 29, 72, 0.25); 4th value is Alpha transparency for background only.
Live Visual Preview (Notice Text Readability!)

rgba(225, 29, 72, 0.2) (Background faded, text stays 100% sharp!)
Opacity vs rgba() Syntax
/* 1. Opacity: Whole element + child text becomes translucent */
.alpha-op  { opacity: 0.4; background-color: #e11d48; }

/* 2. RGBA: ONLY background is translucent; text is 100% solid white! */
.alpha-rgb { background-color: rgba(225, 29, 72, 0.2); color: #9f1239; }

Position (static, relative, absolute, fixed, sticky)

Positioning

1. What It Does (Plain English)

The position property takes elements out of default document flow to anchor, shift, or stick them anywhere on screen.

2. How It Works in CSS

  • static: Normal natural document flow (default).
  • relative: Shifted from its normal spot using top/left without disturbing neighbors.
  • absolute: Placed relative to its nearest positioned ancestor.
  • fixed: Pinned to the browser window; ignores page scroll.
  • sticky: Scrolls normally until reaching threshold (e.g. top: 0), then sticks.

z-index (Stacking Order)

Positioning

1. What It Does (Plain English)

Controls the 3D stacking order along the Z-axis (towards/away from your eyes). When two elements overlap, the one with a higher z-index number floats on top.

2. How It Works in CSS

  • CRITICAL REQUIREMENT: z-index ONLY takes effect on elements that have a position other than static (e.g. relative, absolute, fixed).
  • Default is auto (or 0). Positive values lift upward; negative values tuck underneath.
⚠️ Most Common Mistake: Setting z-index: 9999 on a standard static div does nothing! Add position: relative to turn on z-index!

.card-middle { position: absolute; z-index: 2;  background: #0284c7; }
.card-top    { position: absolute; z-index: 10; background: #e11d48; }

Media Queries (@media (max-width: ...))

Responsive

1. What It Does (Plain English)

Media queries are the engine of Responsive Web Design. They tell CSS: "Only activate these styles when the user's browser window is within a specific width!" (like on mobile phones).

2. How It Works in CSS

  • @media (max-width: 768px) { ... } triggers when the viewport width is 768px or narrower.
  • Styles outside the media query serve as defaults; rules inside override them on smaller devices.
Live Visual Preview (Resize Browser to Test!)
Desktop Screen (> 768px): Ocean Blue Theme Mobile Screen (≤ 768px): Crimson Red Theme!
Responsive Breakpoint Syntax
/* Desktop Default (Blue) */
.mq-test-box { background-color: #0284c7; color: #ffffff; }

/* Mobile Viewport Trigger (<= 768px) */
@media (max-width: 768px) {
  .mq-test-box {
    background-color: #e11d48; /* Turns Crimson Red on phones! */
  }
}

% in Animation (Multi-Step Keyframes: 0%, 50%, 100%)

Animations

1. What It Does (Plain English)

Instead of only from (0%) and to (100%), percentage milestones let you storyboard complex choreography with multi-stop scenes at 0%, 25%, 50%, 75%, and 100%.

2. How It Works in CSS

  • 50%: Morphs midway into a scaled-up rose-red circle!
  • 100%: Seamlessly shifts to an emerald green badge.
